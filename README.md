# 🔐 SIDAS - Sound Intrusion Detection System

## 📌 Overview

SIDAS is an IoT-based system designed to enhance elderly safety by detecting abnormal sound events such as falls, shouting, or disturbances.

## 🎯 Problem Statement

Elderly people living alone are vulnerable to emergencies. Existing systems like CCTV and wearable devices have limitations such as privacy issues and user dependency.

## 🚀 Solution

This project uses an ESP32 and sound sensor to detect abnormal sound and generate real-time alerts through a web dashboard.

## ⚙️ Hardware Used

* ESP32
* KY-038 Sound Sensor
* LED
* Buzzer

## 💻 Tech Stack

* Arduino (Embedded C)
* Node.js (Backend)
* HTML/CSS/JavaScript (Frontend)

## 🧠 Working

Sound → ESP32 → Threshold Check → Alert → Server → Dashboard

## 📊 Performance

| Environment | Accuracy |
| ----------- | -------- |
