ESP32 + KY-038 Sound Sensor Connection Guide

🔊 KY-038 Sound Sensor

  • VCC → ESP32 3.3V
  • GND → ESP32 GND
  • D0 → ESP32 GPIO 34
  • A0 → ESP32 GPIO 35 (Optional)

💡 LED Indicator

  • LED (+) → 220Ω Resistor → ESP32 GPIO 2
  • LED (-) → ESP32 GND

🔔 Active Buzzer

  • Buzzer (+) → ESP32 GPIO 4
  • Buzzer (-) → ESP32 GND

⚠️ Important Notes

  • Power: KY-038 uses 3.3V from ESP32 (NOT 5V)
  • LED: Always use a 220Ω resistor to protect the LED
  • Buzzer: Use an active buzzer (has built-in oscillator)
  • GND: All GND connections must be common (connected together)
  • Sensitivity: Adjust the potentiometer on KY-038 to set detection threshold
  • GPIO 34/35: These are input-only pins, perfect for sensors
